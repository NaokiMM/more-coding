# 教材ロケール（JP/EN/CN）対応

## 概要

- 教材を始める前に、プルダウンで **JP / EN / CN** を選択する。
- 選択後は URL に `?locale=jp` 等が付与され、**途中で言語変更はできない**。
- S3 パスは **`questions/{locale}/{教材種類}/{レベル}/{内容}`** に変更済み。

## 実装済み

### 共通

- **`src/lib/learnLocale.ts`**  
  - `LearnLocale` 型、`LEARN_LOCALES`、`getQuestionsJsonUrl(baseUrl, locale, technology, course, filename)`、`isValidLearnLocale`、`buildLearnHref`
- **`src/hooks/useLearnLocale.ts`**  
  - `useSearchParams` から `locale` を取得し、`learnHref(path)` で `?locale=` 付きリンクを生成
- **`src/components/LearnLocaleSelect.tsx`**  
  - 教材開始前の「教材の言語を選択」画面（JP/EN/CN プルダウン + 「学習を始める」）

### 教材トップでロケール選択 + learnHref

- **React** (`/learn/react`) … ロケール未選択時は `LearnLocaleSelect`、レベルリンクは `learnHref` 使用

### レベル・カテゴリ・study で locale 必須 + S3 新パス

- **React**  
  - `/learn/react/associate` … `useLearnLocale`、未設定時は `/learn/react` へリダイレクト、リンクは `learnHref`
  - `/learn/react/associate/[categoryId]/study` … `searchParams.locale` 必須、`getQuestionsJsonUrl` で取得
  - `/learn/react/professional/.../study` … 同様
  - React Associate の `StudyClient` … 戻りリンクに `learnHref` 使用
- **Next.js**  
  - `/learn/nextjs/associate/[categoryId]/study` … locale 必須 + `getQuestionsJsonUrl`
- **Express**  
  - `/learn/express/associate/[categoryId]/study` … locale 必須 + `getQuestionsJsonUrl`

## 他教材に同じパターンを適用する場合

以下の 3 点を、各教材・レベルごとに揃える。

### 1. 教材トップ（例: `/learn/nextjs/page.tsx`）

- `useLearnLocale()` を利用
- `!hasValidLocale` のとき `return <LearnLocaleSelect techPath="/learn/nextjs" techName="Next.js" />;`
- レベルへのリンクを `href={learnHref("/learn/nextjs/associate")}` のように `learnHref` に変更

### 2. レベル・カテゴリ一覧（例: `/learn/nextjs/associate/page.tsx`）

- `useLearnLocale()` を利用
- `!hasValidLocale` のとき `useEffect` で `router.replace("/learn/nextjs")`、`return null`
- カテゴリ・戻りリンクをすべて `learnHref(...)` に変更

### 3. study ページ（例: `.../[categoryId]/study/page.tsx`）

- `searchParams` を props に追加
- `locale = (await Promise.resolve(searchParams))?.locale` を取得し、`!locale || !isValidLearnLocale(locale)` なら `redirect("/learn/nextjs")`
- `getCategoryData(categoryId, locale)` のように locale を渡す
- `getCategoryData` 内で  
  `getQuestionsJsonUrl(baseUrl, locale, "nextjs", "associate", category.file)` を使用（教材・レベルに合わせて第3・4引数を変更）

### 4. StudyClient の戻りリンク

- `useLearnLocale()` の `learnHref` を使い、`/learn/nextjs` や `/learn/nextjs/associate` などのリンクを `learnHref("/learn/nextjs")` のように変更

## S3 バケット側

- パスを **`questions/{locale}/{教材種類}/{レベル}/{ファイル名}.json`** に配置する。
- 例: `questions/jp/nextjs/associate/api-middleware.json`
